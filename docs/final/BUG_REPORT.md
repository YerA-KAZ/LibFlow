# LibFlow — Bug Report

Күні: 2026-11-04. Түзетулер осы workspace-та; ретест дәлелдері `evidence/` ішінде.
P1 — құрастыру/негізгі функцияға кедергі; P2 — маңызды UI/дерек ақауы;
P3 — төмен маңыздағы ақпараттық ақау. Бұл есеп табылған нақты жағдайларды сипаттайды.

## BUG-01 · Docker image ішінде realtime модулі жоқ — P1, түзетілді

- Қадамдар: бұрынғы Dockerfile бойынша `app.py` және seed-ті ғана көшіру;
  `uvicorn app:app` іске қосу.
- Күтілетіні: REST/WS сервері іске қосылады.
- Нақтысы: `app.py` ішіндегі `from backend.realtime import hub` импортына
  image ішінде `backend` пакеті де, `realtime.py` файлы да жоқ.
- Себеп: realtime қосылғаннан кейін Docker COPY/entrypoint жаңартылмаған.
- Түзету: `__init__.py`, `app.py`, `realtime.py`, seed `backend/` ішіне көшіріледі;
  entrypoint `backend.app:app` болды.
- Ретест: `test_docker_package_import_in_clean_directory` PASS — таза каталогқа
  image-тегі пакет құрылымы көшіріліп import және WS route тексерілді.
  Docker daemon ішінде толық image build бұл тексеріске жатпайды.

## Белгілі шектеулер және орта диагностикасы

- Локалды аккаунттар, ортақ құрылғы кэші, API-де server auth/RBAC жоқ:
  архитектуралық шектеу; осы оқу тапсырмасында production auth жасалды деп саналмайды.
- Аудио панелі нақты аудионы ойнатпайды; пікірлер экран жадында ғана сақталады.
- Камерамен шынайы QR декодтау мен физикалық желіні өшіру-қосу қолмен тексеріледі.
- Windows Developer Mode жабық болса pub get desktop plugin symlink сатысында
  тоқтауы мүмкін. Бұл ортада тәуелділіктер шешілгеннен кейін Android/test
  командалары `--no-pub` арқылы орындалды; жүйе баптауы автоматты өзгертілмеді.
- Эмулятордың алғашқы 4GB конфигурациясына host commit memory жетпеді;
  1536MB параметрімен boot сәтті өтті. Gradle heap 3GB, workers=2 болып шектелді.
- Жаңа integration test-тегі `await app.main()` бастапқы `void main` сигнатурасына
  сәйкес келмеді; main `Future<void>` болды. Тест fixture-індегі fake-async күту
  және custom back button finder де түзетілді; олар қолданба қатесі деп саналмайды.
- Starlette/AnyIO deprecation және Java native-access/SDK XML ескертулері
  логтарда сақталған; оларды қолданба тестінің PASS нәтижесімен шатастырмаңыз.
- `flutter doctor -v` Android toolchain/license күйін дайын деп көрсетті.
  Екі диагностикалық санат қалды: PATH-та бөлек Dart SDK бар және Windows
  desktop үшін Visual Studio C++ компоненттері толық емес. Осы тапсырмадағы
  Android build/test Flutter-дің bundled Dart SDK-сын қолданды; жүйелік PATH
  пен Visual Studio орнатылымы өзгертілмеді.

- Release engine JAR файлдарына HEAD сұрауы 200 қайтарды, бірақ GET жүктеуі
  ілгерілемеді. Release әрекеті тоқтатылып, тапсыру үшін қалыпты `lib/main.dart`
  entrypoint-інен debug APK жиналды. Release APK дайын деп көрсетілмейді.

- APK-ны іске қосу скриншотында эмулятордың «System UI isn’t responding»
  терезесі байқалды (LibFlow атауы бар ANR емес). Wait таңдалды, қолданбаның
  Login экраны қайта тексерілді. Native интеграциялық сценарий бұған дейін
  PASS болды; эмулятор ресурсының бұл ескертуі қолданба қатесі ретінде бекітілмейді.
