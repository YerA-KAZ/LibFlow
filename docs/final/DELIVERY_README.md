# LibFlow — тапсыру жинағы

Күні: 2026-11-04. Нұсқа: 1.0.0+1.

| Папка/файл | Мазмұны |
|---|---|
| `apk/LibFlow-1.0.0.apk` | Android debug орнату файлы |
| `source/` | Flutter, FastAPI, тесттер, платформалық бастапқы код |
| `LibFlow_source.zip` | Сол бастапқы кодтың тасымалдауға арналған архиві |
| `documents/USER_GUIDE.md` | Орнату және пайдалану нұсқаулығы |
| `documents/ARCHITECTURE.md` | Архитектура, деректер қоры, API |
| `documents/architecture.png` / `.svg` | Архитектуралық диаграмма |
| `documents/TEST_REPORT.md` | Test Case қадамдары, expected/actual және қорытынды |
| `documents/BUG_REPORT.md` | Қателер, қайталау қадамдары, түзетулер |
| `evidence/` | Терминал логтары мен тест нәтижелері |
| `MANIFEST.json` | Файлдар тізімі, өлшемі және SHA-256 |

Презентация мен Demo Video пайдаланушының өзі дайындайды; осы жинаққа
олардың жасанды нұсқалары қосылған жоқ.

Алдымен пайдаланушы нұсқаулығын, әзірлеу үшін `source/README.md` файлын ашыңыз.
Серверді іске қосу және нақты телефонға IP баптауы қажет. APK — оқу/демо
мақсатындағы жинақ; store-ға жариялау сертификаты берілмеген.

Құпия `.env`, PostgreSQL деректері, виртуалды орта, `.git`, build кэші,
жеке құрылғы кэші мен signing key бастапқы код пакетіне кірмейді.
Олардың орнына `.env.example` және таза seed деректері беріледі.
