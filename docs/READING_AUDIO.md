# Кітап оқу және MP3 аудио

## Қолдану

1. Қосымшаны қайта іске қосып, жүйеге кіріңіз.
2. Басты экрандағы **«Оқу және аудио · демо»** карточкасын табыңыз.
3. «Демо кітапты оқу» — үш тарауды ашу; тізімнен не алдыңғы/келесі
   батырмаларымен тарау ауыстыру. Жоғарғы баптаудан қаріп/фонды өзгертіңіз.
4. Экранды жауып қайта ашқанда тарау мен салыстырмалы айналдыру орны қалпына келеді.
5. «Демо аудионы тыңдау» — бірінші тараудың ағылшын тіліндегі нақты MP3 жазбасы.
   Play/Pause, ±10 секунд, уақыт жолағы және 0.75–2x жылдамдық қолжетімді.
6. Сақталған орын бар болса, сол жерден жалғастыру ұсынылады. Негізгі Play
   батырмасы ағымдағы/бастапқы жерден ойнатады; аяқталған аудио қайта басталады.

Лицензия/диктор/дереккөз: [CONTENT_LICENSES.md](../assets/books/CONTENT_LICENSES.md).
Демо серверден тәуелсіз; ол каталогқа автоматты импортталып не басқа
кітаптардың мәтіні/аудиосының орнына қосылмайды.

## Өз кітабыңызды қосу

Каталог → кітап қосу/өңдеу:

- Электронды кітап белгісін қосып, толық мәтінді немесе «Тарау қосу» арқылы
  атауы мен мәтіні бар тарауларды енгізіңіз. Тараулар болса, оқу соларды қолданады.
- Аудио белгісін қосып, қолжетімді **HTTPS MP3** сілтемесін енгізіңіз.
  Бет/YouTube сілтемесі аудиофайлдың орнына жүрмейді. Сервер duration және
  seek үшін дұрыс Content-Type/Content-Length/Range жауаптарын беруі керек.
- Нақты ұзақтық плеерде файлдан анықталады; формадағы ұзақтық — сипаттамалық белгі.
- Контент жоқ болса, оқу/тыңдау батырмасы белсенді болмайды. Қате файл/желі
  кезінде түсіндірме және қайта көру батырмасы көрсетіледі.

Backend коды жаңарғандықтан, бұрыннан қосулы API серверін тоқтатып қайта
іске қосу керек: оның ескі схемасы жаңа өрістерді қабылдамайды.
Жаңа тәуелділіктерден кейін hot reload жеткіліксіз — толық Flutter restart керек.

## Деректер және үйлесімділік

REST/JSON-ға `chapters: [{id, title, text}]` және `audioUrl: string | null`
қосылды. Ескі жазбаларда тараулар әдепкіде бос, URL null. Тараулар болмағанда
`readingContent` бір `legacy` тарауы ретінде ашылады. JSONB құрылымына
SQL миграция қажет емес. Тарау ID-лері өзгертілмесе, өңдеуден кейін bookmark сақталады.

`media_progress.json` application-support каталогында, каталогтан бөлек сақталады:
кітап ID → chapterId, scrollFraction (0–1), fontSize, readerTheme, audioMs, audioSource.
Жазулар кезекпен, уақытша файлды ауыстыру арқылы орындалады. Аудио сілтемесі
өзгерсе, бұрынғы файлдың позициясы қолданылмайды. Жойылған тарауда bookmark
бірінші тарауға қайтады. Кітап мәтіні өзгерсе, салыстырмалы орын жуық қалпына келеді.

Аудио progress әр шамамен 5 секундта, pause/seek/жабылуда сақталады.
Оқу progress айналдырудан 350ms кейін, тарау ауыстыруда/жабылуда сақталады.
Кэш серверден жаңарғанда progress өшірілмейді. Аккаунттарға ортақ құрылғылық
сақтау моделі сақталған; бұл серверлік синхрондау емес.

## Плеер өмірлік циклі

`just_audio` және `audio_session` қолданылады. Жаңа плеер/кітап ашылғанда
алдыңғысы кідіреді; экран жабылғанда ресурстар босайды. Қосымша foreground-тан
шыққанда аудио кідіреді. Фондық playback, lock-screen басқару, remote MP3
жүктеп сақтау және TTS бұл нұсқаға кірмейді.

## Тексеру

```powershell
flutter analyze --no-pub
flutter test --no-pub --reporter expanded
backend/.venv/Scripts/python.exe -m pytest backend -q --tb=short
flutter test --no-pub integration_test/media_playback_test.dart -d emulator-5554
```

Unit/Widget тесттері: модельдің JSON айналымы, legacy/empty, progress restart және
book isolation, бүлінген файл, play/pause/seek/speed, resume/source өзгеруі,
completion/replay, бір белсенді плеер, қате/retry, тараулар мен scroll/font қалпына келуі.
Backend тесттері: PostgreSQL roundtrip, URL тазарту, HTTPS және қайталанған тарау ID.
Native тест actual bundled MP3 декодталуын, ұзақтығын, position жылжуын,
pause/seek/speed/resume және офлайн тарау ауысуын тексереді.
Нақты нәтижелер `build/media-evidence/` логтарында сақталады.


## Осы өзгерістің нақты нәтижелері

- `flutter analyze --no-pub`: No issues found.
- Толық Flutter жиыны: **73 тест өтті**.
- Соңғы плеер өзгерістерінен кейінгі media ретесті: **11 тест өтті**.
- PostgreSQL/backend толық жиыны: **24 тест өтті**.
- Android 17 API 37 эмуляторы: **1 нақты media интеграциялық тест өтті**.
  Bundled MP3 ұзақтығы 40–60 секунд аралығында, position ≥1200ms болып
  жылжуы, pause, seek=10s, speed=1.5, қайта ашқанда resume=10s тексерілді.
- Android-тағы оқу тексерісі: демо тарауының нақты мәтіні, келесі тарау және
  дискіге сақталған chapterId тексерілді.
- Жұмыс істеп тұрған API жаңа `chapters`/`audioUrl` OpenAPI келісімімен қайта іске қосылды.

Автоматты тексеріс дыбыс қозғалтқышының decode/playback күйі мен уақытын растайды;
компьютер динамигінің физикалық дыбыс деңгейі пайдаланушы баптауына байланысты.
